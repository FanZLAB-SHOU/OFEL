ALSCL

Age- and length-structured catch-at-length models

ALSCL fits fisheries population models to fishery-independent survey length data. It provides an age-structured model (ACL) and a joint age–length model (ALSCL), allowing researchers to examine how growth and size-dependent mortality affect stock assessment.

Built in R with Template Model Builder (TMB), the package includes tools for simulation, model fitting, diagnostics, retrospective analysis, comparison, and plotting. Online documentation provides worked examples and function references in English and Simplified Chinese.
